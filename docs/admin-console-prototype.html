Planned HTTP dev-server proxy first; optional PHP-FPM/FastCGI later with explicit script mapping, upload limits and timeout handling. PHP must never be served as plain source.

Databases

Not implemented

Planned read-only connection health checks for MySQL/MariaDB and an optional protected link to a separately installed phpMyAdmin.
